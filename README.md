# Netflix-Powerbi-Dashboard
Power BI dashboard project analyzing Netflix content trends, ratings, genres, and global distribution using real-world data.

I built this Power BI dashboard to explore and analyze the Netflix Titles dataset. The goal of this project was to understand content trends, rating distribution, genre popularity, and global content presence using data visualization.

This project helped me improve my data cleaning, modeling, and dashboard design skills.

📊 What I Analyzed

Total number of Netflix titles

Movies vs TV Shows distribution

Most common content ratings

Popular genres

Content growth by release year

Country-wise content distributio
